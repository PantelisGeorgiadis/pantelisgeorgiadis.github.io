# pantelisgeorgiadis.github.io

Personal portfolio page listing my public GitHub projects and gists.

Live at **https://pantelisgeorgiadis.github.io**

## Stack

- Vanilla HTML / CSS / JavaScript — no build step, no dependencies
- Data loaded at runtime from the [GitHub REST API](https://docs.github.com/en/rest) and [npm Downloads API](https://api.npmjs.org/)

## Run locally

Open `index.html` in a browser, or serve it with any static server:

```sh
npx serve .
```
